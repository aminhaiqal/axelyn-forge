# Axelyn Forge API

FastAPI service for the public service catalog, Clerk-protected resume sources, evidence-preserving OpenRouter resume structuring, per-resume layout binding, JSON-to-SDT rendering, LibreOffice conversion, and job-match analysis. Every imported Word layout receives its own example JSON, Draft 2020-12 schema, private binding manifest, and SDT-tagged source copy. Resume originals and generated files remain owner-scoped in private object storage. See the repository root README for development and deployment instructions.
