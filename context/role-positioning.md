# Role Positioning

## Software Engineer

Emphasize:
- End-to-end software delivery
- Backend engineering
- APIs
- Data models
- Production systems
- Testing
- Deployment
- Reliability
- Integrations
- Requirements translation

Choose projects according to the role rather than including everything.

---

## Backend Engineer

Prioritize:
- Python
- Go
- Django
- FastAPI
- PostgreSQL
- Redis
- REST APIs
- Authentication
- Background processing
- Data ingestion
- Testing
- Docker
- AWS
- Kubernetes
- CI/CD

Project priority:
1. Monitorscape
2. ARIA
3. Pastelocity or Memora depending on requirements

---

## Technical Business Analyst / Systems Analyst

Prioritize:
- Requirements translation
- Stakeholder communication
- Business process understanding
- Process flows
- API design
- Data models
- Integrations
- Technical feasibility
- Validation
- Production handoff

Project priority:
1. Pastelocity
2. Monitorscape
3. Memora or ARIA depending on domain

Core positioning:

Understands both the requirement and what it takes to implement it.

Do not frame the candidate as leaving engineering.

---

## Solutions Engineer

Prioritize:
- Customer/business requirements
- Technical solution design
- APIs
- Integrations
- Data models
- Troubleshooting
- Deployment
- Stakeholder handoff

Strong evidence:
- Pastelocity
- Axelyn client delivery
- Monitorscape

---

## AI Engineer

Prioritize:
- ARIA
- RAG
- Structured outputs
- LLM integration
- Validation
- Evidence attribution
- Document processing
- AI reliability
- Qwen fine-tuning experiment

Preferred positioning:

Software Engineer building AI-enabled systems.

Do not position as an AI researcher.

## Data Engineering

Prioritize:
- ARMO
- Monitorscape
- Multi-source ingestion
- ETL-style transformations
- PostgreSQL
- SQL
- Scheduled processing
- Validation
- External sources
- Recovery mechanisms

Emphasize experience with unreliable and changing external sources.
