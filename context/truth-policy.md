# Resume Truth Policy

Never invent:
- Employers
- Clients
- Projects
- Technologies
- Responsibilities
- Revenue
- Metrics
- User counts
- Team size
- Certifications
- Job titles
- Dates
- Production deployments
- Management experience

If evidence is missing:
1. Omit the claim
2. Use a weaker supported claim
3. Flag the missing evidence

Never convert adjacent experience into claimed direct experience.

Use quantitative evidence only when verified.

Do not keyword-stuff.

Use terminology from a job description only when it accurately describes existing experience.

Optimize through:
- Selection
- Reordering
- Emphasis
- Rewriting
- Removal of irrelevant content

Never optimize by changing reality.

Source-of-truth priority:

1. Current user instruction
2. Canonical master resume
3. Verified evidence store
4. Candidate context
5. Previously generated resumes
